> A music player built exclusively for study purposes. It is capable of downloading music directly from YouTube links, playing it, and even creating playlists with selected songs.
### Features
- This project can download music directly from YouTube links.
- This project supports creating and editing playlists.
- This project has a very intuitive interface.
- This project is lightweight.
- This project stores data (playlists, volume preferences, and the elapsed time of the last played song) between sessions.
- This project is made 100% in Python.
## How to Install and Run
Clone the repository.
Make sure Python 3.12.3 is installed.
The following libraries must be installed for Python 3.12.3: customtkinter, pygame, mutagen, pillow (only the PIL module), and yt-dlp.
Run the program using VS Code or any IDE of your choice.

It is also possible to install the version containing the entire project as an executable. This eliminates the need to install Python 3.12.3 and the libraries mentioned above, since the executable works as a standalone package, bundling the main program, the required libraries, and Python itself.
